nuvx / DOCUMENTATION

A little context
before you begin.

nuvx is actively being built. This guide tells you what works today, what is planned, and how to run the code if you want to explore or contribute.

There is no installable release yet.

The Android and desktop app interfaces and playback are not implemented. Do not expect an APK, installer, TV app or Wear OS build. Watch the repository for release announcements.

01 — START HERE

What is nuvx?

nuvx is an open-source music player project built with Kotlin Multiplatform and Compose Multiplatform. It connects to YouTube Music through interchangeable backend engines. It is independent software and is not made, endorsed or sponsored by YouTube or Google.

The project is early-stage. Backend experiments and shared models exist; user-facing apps and playback remain future work. See the verified progress and known limitations.

03 — FOR CONTRIBUTORS

Build from source

These steps prepare the shared project and run its desktop unit tests. They do not install a usable music player.

  1. Install the toolchain. Use Temurin JDK 25 to run Gradle, JDK 27 for the desktop target, and Android SDK API 37. See the complete toolchain notes.
  2. Build eXcor locally. nuvx currently consumes its alternative engine from Maven Local. Clone eXcor and run:
    ./gradlew publishAndroidPublicationToMavenLocal publishJvmPublicationToMavenLocal publishKotlinMultiplatformPublicationToMavenLocal
  3. Clone nuvx and build.
    git clone https://github.com/bxanedot/nuvx.git
cd nuvx
./gradlew :shared:desktopTest
    On Windows, use gradlew.bat. Gradle can provision the JDK toolchain; if needed, set org.gradle.java.installations.paths to your JDK 27 location.
  4. Optional live backend check. This reaches YouTube Music over the internet and may change as the service changes:
    NUVX_LIVE=1 ./gradlew :shared:desktopTest --tests '*LiveBackendTest*'

Android SDK local configuration may require a gitignored local.properties with sdk.dir set to your SDK path. iOS targets cannot currently be built on Windows.

04 — STREAMING

Music engines

The shared code exposes a MusicBackend interface. InnerTubeX is the default and has passed live search, radio and audio-stream checks. eXcor search and radio work, but YouTube currently refuses its stream requests because it does not mint PO tokens. With fallback enabled, nuvx routes stream requests to the other engine.

Backend availability depends on YouTube Music, network access and the upstream projects. This can change without notice; see the current blocker list.

05 — DATA & PRIVACY

What to expect

The public website is static and does not provide account creation or a contact form. The app is not yet released, so its final data handling has not been established. Backend requests made during development can communicate with YouTube Music and the selected engine. Review the source and upstream service terms before using development builds.

Read the website privacy notice and terms.
