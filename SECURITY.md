# Security Policy

Nuvx includes Android, Android TV, Wear OS, desktop, web and browser extension, and Listen Together server components.

## Supported versions

Security fixes are prioritized for the latest published stable release of each component and the current `main` branch. Nightly builds and older releases may not receive updates.

## Reporting a vulnerability

Use GitHub's **Report a vulnerability** option on the repository's Security page to send vulnerability details privately. Do not post exploitable details in public issues, pull requests, or Discord.

If private reporting is unavailable, email [bxanee@gmail.com](mailto:bxanee@gmail.com) instead.

Include the affected component and version, platform, steps to reproduce, and potential impact. Redact passwords, tokens, cookies, private listening data, and other personal information from logs or screenshots.

## Disclosure

Please allow time for investigation and a fix or mitigation before publishing technical details. We will coordinate disclosure where possible. This project does not guarantee a response or remediation timeline.

For non-sensitive bugs and feature requests, use [GitHub Issues](https://github.com/bxanedot/nuvx/issues).
