nuvx / DOCUMENTATION

A little context
before you begin.

nuvx is actively being built. This guide tells you what works today, what is planned, and how to run the code if you want to explore or contribute.

The current stable release is available.

Get the Android and desktop apps from the latest release; the phone app installs the Wear OS app on your watch. In a browser, use the web player.

01 — START HERE

What is nuvx?

nuvx is an independent, open-source YouTube Music player. Android uses Kotlin and Compose, Windows/Linux/macOS share one Rust/egui desktop app, and the iOS source port uses SwiftUI with its native/KMP playback backend. The web player uses React and TypeScript. nuvx is not made, endorsed or sponsored by YouTube or Google.

IPHONE & IPAD

Install and sideload on iOS

This port has not yet been verified on an Apple device. Look for Nuvx-<version>-build<number>-ios-unsigned.ipa in the latest release assets. If no IPA is listed, it has not been published: an APK, source ZIP or desktop package will not work.

  1. Choose a signing tool. On Windows or macOS, use Sideloadly, AltStore Classic, or SideStore. Follow the tool's official prerequisites, including Apple device drivers on Windows. No jailbreak is needed.
  2. Connect and install. Connect an unlocked iPhone or iPad by USB, trust the computer, and import the IPA into the tool. Sign with your own Apple Account. Never send account credentials to nuvx or an unofficial signing website.
  3. Allow the developer app. If prompted, trust the profile in Settings → General → VPN & Device Management. Enable Developer Mode in Settings → Privacy & Security, restart, and confirm.
  4. Keep it signed. Free-account signatures normally expire after 7 days; refresh before expiry. Free accounts normally allow three active sideloaded apps, and the signing tool itself may use one slot. Use the same account and bundle identifier for updates to preserve data.

Opening an unsigned IPA in Files does not install it. Widgets, Live Activities, App Groups and iCloud depend on signing capabilities and are not guaranteed with free accounts. Do not uninstall to troubleshoot before backing up downloads and settings.

No Mac? The Apple builds workflow uses GitHub-hosted Macs. Successful runs upload unsigned IPA and macOS artifacts for 14 days; downloading CI artifacts requires GitHub login. A build passing CI does not verify device playback.

03 — FOR CONTRIBUTORS

Build from source

To just use nuvx, download the latest release instead.

  1. Android/Kotlin. Install JDK 25 and Android SDK API 37, then run:
    git clone https://github.com/bxanedot/nuvx.git
cd nuvx
./gradlew :shared:jvmTest
./gradlew :app:assembleDevDebug
    On Windows, use gradlew.bat. Set ANDROID_HOME or the gitignored local.properties SDK path. Android's eXcor dependency is checked into the third-party Maven repository.
  2. Desktop. From app/desktop, run cargo test --locked and cargo build --release --locked. macOS uses this Rust source, not SwiftUI; Linux also needs the system libraries listed in the desktop workflow.
  3. iOS. On an Apple silicon Mac with current Xcode, Rust, CMake, a JDK and XcodeGen, run bash scripts/bootstrap-apple.sh from app/ios. Open mobile/Nuvx.xcodeproj or run the unsigned IPA packaging script. Windows/Linux cannot build the iOS app; use the Apple builds workflow if you do not have a Mac.

See the repository's build instructions for each app. Never commit signing credentials or generated frameworks.

04 — STREAMING

Music engines

Backend availability depends on YouTube Music, network access and upstream projects. Android can try its eXcor fallback when the primary resolver finds no stream. That artifact is Android-only; the iOS port keeps its existing native/KMP resolver and does not expose an unsupported fallback toggle.

Service changes can affect playback without notice. Build checks alone do not prove that streaming works on a device.

05 — DATA & PRIVACY

What to expect

The public website is static and does not provide account creation or a contact form. The apps talk to YouTube Music and to the services you choose to connect. Their data handling has not been independently audited yet. Review the source and upstream service terms before use.

Read the website privacy notice and terms.
