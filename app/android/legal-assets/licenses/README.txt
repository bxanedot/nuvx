Nuvx Android license files

The app source is available at https://github.com/bxanedot/nuvx.
LICENSE is the project default license. LICENSES.md maps files that use other terms; the corresponding full license texts are included beside it.
THIRD_PARTY_NOTICES.txt identifies bundled native libraries, Android dependencies, and AutoMix models. LICENSE-MIT-Model-Weights.txt contains the model notices; LICENSE-MIT-Liquid-Glass-Easy.txt contains the pill-motion attribution. Dependency notices embedded by Android libraries are retained under META-INF/ in the APK.
